## 用途

本文是**命名、定位与界面用语**的唯一真源。改动产品名、渠道名、导航位置或核心术语前，先改这里，再同步到各端；各端出现冲突时以本文为准。

代码层的真源另行指定，不在此重复：

| 主题 | 真源 |
| :--- | :--- |
| 能力与层级 | `Beancount-Trans-Frontend/src/capabilities/registry.ts` |
| Web 语义色 | `Beancount-Trans-Frontend/src/styles/tokens.scss` |
| Web 组件色阶 | `Beancount-Trans-Frontend/src/styles/element/index.scss` |
| 移动端主题 | `Beancount-Trans-Mobile/lib/theme/product_colors.dart` |
| 图标与启动图 | `Beancount-Trans-Mobile/design/` |

## 一、命名双轨

- **财见（Caijian）**：产品名。出现在用户可见界面、应用名、启动图、Web 顶栏与页面标题。
- **Beancount-Trans**：项目名。出现在开源仓库、文档站、镜像与包名、GitHub 链接。

| 渠道 | 使用 | 说明 |
| :--- | :--- | :--- |
| Web 顶栏 | 不设品牌区 | 顶栏只放导航与账户操作；产品名由页面标题与 favicon 承担 |
| Web 页面标题 | 财见 | `index.html` 的 `<title>` 与 favicon |
| Mobile 应用名 | 财见 | Android `android:label`、iOS `CFBundleDisplayName` |
| 文档站 | Beancount-Trans | 站点标题、导航栏与社交卡保持项目名 |
| GitHub / 镜像 / 包名 | Beancount-Trans | 不改 |
| 分享图 / 导出物 | 财见 | 页眉只写产品名 |

禁止：在同一界面混用两名；把 Beancount-Trans 写进用户可见的按钮或标题；给产品名加版本号或后缀。

## 二、项目定位

| 端 | 一句话定位 | 目标用户 | 不承担 |
| :--- | :--- | :--- | :--- |
| Web 平台 | 上传账单，解析成可审计的 Beancount 账本，并完成写入、对账与分析 | 需要集中处理多来源账单的个人用户 | 长期离线编辑、多人协作 |
| Mobile | 财见的手持入口：查看账本、审核待办、与 Copilot 对话 | 需要随时查看与快速审核的用户 | 批量账单解析、完整配置管理 |
| 文档站 | 开源项目的教程、操作指南、参考与理念说明 | 使用者与自托管者 | 产品功能本身 |
| 高级：本地账本（Git 同步） | 让账本以自管 Git 仓库为准的高阶选项 | 愿意用 Git 管理账本的高级用户 | 普通用户的默认路径 |

**普通用户登录即完整可用**：解析、写入平台账本、文件、配置、Copilot、Fava 都不依赖 Git。Git 同步只改变账本的归属方式（账户以账本为准、写入需「提交到账本」），不改变其余功能。

## 三、能力层级

三层会话派生能力，前端只认能力、不认来源：

| 层级 | 判定 | 能力范围 |
| :--- | :--- | :--- |
| guest | 无登录令牌 | 解析闭环：上传、解析、编辑结果、预览/复制/下载 |
| member | 已登录 | 上述 + 账本写入、文件、配置、模板、待办、审核、Copilot、Fava、设置 |
| git | 已登录且已关联仓库 | 上述 + 仓库同步（`git.sync`） |

能力清单与门禁文案以 `capabilities/registry.ts` 为准；新增能力必须先在该文件登记最低层级。

## 四、界面用语

| 场景 | 用语 | 不要写 |
| :--- | :--- | :--- |
| 解析结果落到平台账本 | 写入账本 | 入账、保存、导入 |
| Git 用户把条目写回仓库 | 提交到账本 | 同步、推送 |
| 设置中的 Git 页签 | 高级：本地账本 | Git 同步、仓库设置 |
| 打开 Beancount 报表 | 用户菜单 → 打开 Fava | 财务报表、平台账本 |
| 未启用 Git 的账户管理 | 账户管理 | 账本账户（仅在需要区分时使用） |

## 五、导航结构

- 顶栏一级：Copilot → 账单解析 → 文件管理 → 解析配置 → （状态区）主题、Star、身份。
- 用户菜单：待办列表、打开 Fava、教程、个人设置、退出登录。
- 游客没有用户菜单，只见「游客 · 解析模式 / 登录 / 注册」。

新增一级导航前先问：它是否服务所有登录用户的核心流程？否则放进用户菜单或设置页。

## 六、变更规则

1. 先改真源，再改物料（SVG/PNG/favicon/社交卡）；不允许只改一边。
2. 界面文案改动需同步本文的「界面用语」。
3. 提交前跑审计，三个断言必须为空：

```shell
# 旧品牌色残留
rg -n '#27C5B6|#0D3038|#FF9B2F|#409EFF|#67C23A|#E6A23C|#F56C6C|#909399' \
  Beancount-Trans-Frontend/src Beancount-Trans-Mobile/lib Beancount-Trans-Mobile/design

# 未注册的伪图标组件
rg -n '<i-[a-z]+-[a-z0-9-]+' Beancount-Trans-Frontend/src

# 自定义 Element 命名空间残留（必须使用默认 el）
rg -n '\$namespace|namespace="ep"|\.ep-[a-z]' Beancount-Trans-Frontend/src
```
